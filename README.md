# EK301-Truss-Preliminary-Design
A repository for the matlab code for our EK301 Truss Project, Preliminary Design phase

"EK301_Truss_Analysis.m" is the main code document. 

"savingTrussDesigns.m" is a code document that creates a new .mat file for each truss design. Truss data is loaded within "EK301_Truss_Analysis.m" using load('filename.mat').
